## Live

- Local constellation runtime. No quota. Walks the graph in order.
- Four planes: working dies, episodic is the log, world is canon, audience never rewrites the world.
- Grok rewrites a single node, and only when asked.
- Lens nodes are shot tickets. They do not pretend a clip exists.
